Recommended action: The implementation report SHOULD include those three SoT-registry tests in the executed-test evidence alongside the two named context-manifest tests.

### FINDING-P3-002: "Deterministic projection contract" is, in practice, a byte-copy

Claim: The test asserts exact byte-equality (`read_bytes() == read_bytes()`) for the seven registry inputs, and no dedicated packaged-context-registry generator script exists in `scripts/` or the context module. "Regenerate the packaged snapshot" therefore means byte-copying the source file into `groundtruth-kb/src/groundtruth_kb/context/registries/v1/config/registry/sot-artifacts.toml`.

Evidence: `groundtruth-kb/tests/test_context_manifest.py:106-122`; `groundtruth-kb/src/groundtruth_kb/context/manifest.py:18-20` (`PACKAGED_REGISTRY_ROOT`). No sync/generator script surfaced.

Risk/impact: LOW / informational. A byte-copy is deterministic and achieves exact equality. A TOML parse-and-re-serialize round-trip would NOT be byte-equal and would fail the test.

Recommended action: Implementation MUST produce the packaged snapshot by copying the exact source bytes, not by re-serializing TOML, and confirm `cmp` / blob-SHA equality before filing the report.
