## Shared-Storage Disclosure

`groundtruth.db` is a large, actively multi-session-written SQLite file; this thread's finalization commit necessarily captures the full current blob state (all pending MemBase rows across concurrent sessions), not only this thread's five rows, because Git cannot partially commit within one binary file. This is the established repo pattern for DB-touching VERIFIED finalizations. Each individual row carries its own independent `changed_by`/`changed_at`/`change_reason` audit trail inside MemBase regardless of which git commit captures the snapshot, so this does not bundle unreviewed cross-thread *content* -- it bundles already-individually-governed rows into one binary snapshot. The recurring `.git` object-store growth this causes is a tracked, not-yet-implemented platform concern (`REQ-GTKB-DB-STORAGE-OBJECT-STORE-BLOAT-001`, WI-5431); it does not block this narrowly-scoped, independently-verified insertion.
