# Independent hygiene assessment

Use only in the reviewing role established by the current literal init binding.
Read the dispatched artifact, current work item and single parent project,
formal intent, scope, linked tests and exact attempt through the CLI.
Review independence belongs to session contexts, not harness names.

Assess the complete selected outcome and consumers: authored sources, schemas,
CLI/services, baseline instructions, tests and templates. Distinguish source
derivability, installed parity and actual host invocation; none substitutes
for the others.

Execute required specification-derived tests, including meaningful refusals,
scope containment, interruption/recovery and foreign-work preservation.
Compare Git modes and object IDs, not content hashes alone. State the exact
frozen scope. Distinguish clean final runs from earlier diagnostics, separately
corrected cases and tests that merely collected.

Confirm retired material no longer acts as current authority. Surviving
obligations require current behavioral coverage or explicit receiving work.
Removing an assertion does not prove its underlying behavior correct.
Read current Bridge phase rules and author the complete verdict yourself.
Deliver through the CLI under the exact artifact claim; the harness only verifies.

Perform no operational mutation that this assessment will verify. Do not
harvest decision history, assign work to peers, mint permission records or infer
completion of other project members. Report evidence, remaining work and
material questions requiring owner direction.
