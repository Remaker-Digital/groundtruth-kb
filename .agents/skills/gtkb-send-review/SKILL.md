# Send an implementation proposal for review

This is an alias for [gtkb-bridge-propose](../gtkb-bridge-propose/SKILL.md).
Read and follow that shared skill in the current Prime Builder context and
explicitly selected activity. The supplied work item and current canonical
context determine the scope.

Author the complete NEW or REVISED message, claim the exact next artifact and
deliver the authored bytes through the native CLI. The writer validates
provenance and routing; the agent supplies both. Filing the proposal is not a
dispatch of another agent.

Report the native delivery result and current message identity, or the exact
refusal and recovery condition. A failed native operation does not authorize
direct file publication or an alternate queue.
